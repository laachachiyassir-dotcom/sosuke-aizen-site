# Sosuke Aizen — site à publier

Le site est statique et prêt pour un hébergement HTTPS. `index.html` ouvre directement le guide des commandes avec les commandes générales et les deux accès univers.

## Pages
- `index.html` : guide fixe des commandes générales et choix d’univers
- `blox-fruits.html` : commandes Blox Fruits
- `bleach.html` : commandes Bleach / Soul Society
- `informations.html` : conditions et informations de confidentialité

## Publication sur GitHub Pages
1. Crée un dépôt GitHub dédié au site et ajoute les fichiers de ce dossier à sa racine.
2. Dans le dépôt, ouvre **Settings → Pages**.
3. Choisis **Deploy from a branch**, puis la branche principale et le dossier `/ (root)`, et enregistre.
4. Quand GitHub indique que la publication est terminée, utilise l’adresse en `https://…github.io/…/` dans Discord.

Le site publié est public. Avec GitHub Free, GitHub Pages nécessite un dépôt public. Le dépôt ne doit contenir que les fichiers destinés à être publics.

## À savoir
La page d’accueil du site est fixe sur écran d’ordinateur. Les pages de commandes détaillées défilent pour afficher toutes les commandes. La partie confidentialité signale les éléments qu’il faut confirmer avant de la présenter comme politique complète.
